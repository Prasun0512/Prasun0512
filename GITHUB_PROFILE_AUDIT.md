The profile now has a strong modern AI architecture surface: enterprise GenAI case studies, agentic AI workflows, RAG quality, document intelligence, email-to-case automation, LLM evaluation, AI operations, reliability, and architecture showcase repositories. These repos should remain the primary public signal.
